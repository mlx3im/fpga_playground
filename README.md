# FPGA Playground

This repository is an educational FPGA project focused on maintainable,
AI-assisted engineering.

Repository-wide agent guidance is in [`AGENTS.md`](AGENTS.md). Every task that
changes architecture, RTL, verification, tooling, or documentation should be
planned using [`docs/PLAN_TEMPLATE.md`](docs/PLAN_TEMPLATE.md).

The initial hardware target is the [Sipeed Tang Nano 9K](docs/boards/tang-nano-9k.md).
The project foundation and repository boundaries are documented in
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
